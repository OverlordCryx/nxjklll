method

The browser does not expose real dBm or network generation. effectiveType caps at "4g", there is no "5g", no RSRP, no RSSI. This page estimates everything:

• ping — rotating CORS endpoints, min of recent probes
• jitter — RFC 3550, rolling window of last 8
• loss — timeouts ÷ total probes
• quality 0-100 — link class + downlink + rtt api + ping + jitter − loss penalty
• dBm — linear map of quality 0→100 to −120→−50 dBm (illustrative)
• generation — match probed throughput and latency to 1G-5G+ thresholds
• grade S-F — S≥90, A≥75, B≥60, C≥45, D≥25

Real dBm needs a native bridge (TelephonyManager Android, CTTelephonyNetworkInfo iOS).
